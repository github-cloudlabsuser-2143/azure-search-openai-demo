# Backend for Azure Search OpenAI Demo

Este es el backend para la demostración de Azure Search OpenAI. Este proyecto utiliza Python y varios paquetes para proporcionar funcionalidades de búsqueda y procesamiento de texto.

## Requisitos

Asegúrate de tener instalados los siguientes requisitos antes de ejecutar el proyecto:

- Python 3.8 o superior
- pip (gestor de paquetes de Python)
